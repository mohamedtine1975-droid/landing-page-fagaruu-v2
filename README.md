# FAGARUU Landing Page

A modern bilingual landing page for FAGARUU, designed to present the product clearly and professionally to users in French and English.

## Overview

This project includes:
- a responsive landing page layout
- a bilingual interface with a language switcher
- reusable sections for value proposition, features, steps, and calls to action
- Tailwind CSS styling for a polished presentation

## Run locally

You can preview the site in two easy ways:

1. Open `index.html` directly in your browser
2. Or serve the project locally with a static server

Example using Python:

```bash
cd "c:\Documents\Landing-page-FAGARUU-main"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
